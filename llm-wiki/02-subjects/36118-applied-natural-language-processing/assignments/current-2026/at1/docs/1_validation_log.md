# AT1 Extraction and Theme Validation Log

## 1. Validation Protocol

The audit was run on 28 July 2026 after the first complete baseline.

- **Extraction check:** inspect every document with fewer than 500 characters
  from native PDF extraction.
- **Match check:** use NumPy seed `42` to select two matching submissions per
  theme, then read the match in its surrounding source context.
- **Recall probe:** search documents without a dictionary match for nearby
  concepts that could reveal a false negative.
- **Decision rule:** a true match must discuss the analytical theme, rather
  than merely contain a word in an affiliation, citation, inquiry heading, or
  unrelated context.

This is a targeted validation audit, not a formal estimate of classifier
accuracy. There is no fully annotated gold-standard corpus.

## 5. Changes Made After Validation

1. Removed bare `education`, `health`, `investment`, and `infrastructure`
   patterns because they produced affiliation, citation, or terms-of-reference
   matches.
2. Replaced them with policy phrases such as `education workforce`,
   `economic contribution`, and `infrastructure capacity`.
3. Replaced the unbounded `pathway.*permanen` expression with a bounded phrase
   pattern so a match cannot span large portions of a normalised document.
4. Added worker-protection phrases including `underpay`, `workplace rights`,
   and `worker protections`.
5. Added `long-term settlement` following the `Sub072` false-negative review.
6. Kept the quantitative denominator at 139 native-text documents and made the
   OCR exclusion explicit.

After refinement, the leading themes remain **skills and essential services**
(approximately 92.8% of usable documents) and **economic contribution**
(approximately 85.6%). The changes therefore improve measurement precision
without reversing the main finding.
