# NLP Lecture Handouts

This folder contains handwriting-friendly PDFs for the current semester.

## Reusable Standard

- `NOTE_STYLE_GUIDE.md`: the writing prompt, content rules, typography,
  code-colour specification, quality checklist, and regeneration workflow for
  all future NLP lecture notes.

## Session 1

- `session-01-comprehensive-notes.pdf`: connected, comprehensive study notes
  grounded in the current Session 1 slide deck and practical notebooks,
  including a notebook-by-notebook study summary and worked-homework lessons,
  using Google Sans throughout.
- `session-01-note-taking-handout.pdf`: an eight-page A4 handout covering the
  NLP pipeline, core vocabulary, preprocessing decisions, representations,
  code-reading prompts, current-semester checks, and retrieval practice.
- Source note: `../session-01-preparation-2026.md`
- Current slide source: `../current-2026/ANLP Session1_Week1.pdf`
- Archived reference slides:
  `../raw/archive-2025/ANLP Session1_Week1_After Session-2.pdf`

The archived 2025 material is conceptual reference only. Update the handout
when current Canvas slides or instructions are available.
