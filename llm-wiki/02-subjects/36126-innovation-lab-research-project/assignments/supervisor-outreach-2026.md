## One-minute proposed concept

**Working title:** Evidence-Grounded LLM Assistant for Explainable Enterprise Graph Analysis

> The assistant would translate an analyst’s natural-language question into graph-analysis operations, profile the network, recommend an appropriate layout or analysis, and explain the result using retrieved technical evidence. Deterministic graph software—not the LLM—would execute graph queries and transformations.
>
> The research would compare a generic LLM, an evidence-grounded assistant, and conventional graph tools on correctness, unsupported claims, explanation quality, task completion, and user understanding. A financial transaction or organisational knowledge graph could provide an enterprise case study.

Keep this tentative until a supervisor helps narrow the question, dataset, evaluation, and semester scope.
