# 36127 Capstone Project Topic Picker — Spring 2026

This clean list contains the **14 topics** from the updated official `Project List s2 2026.pdf`, downloaded from Canvas on 27 July 2026.

## Capstone topics

| ID | Topic and provider | Concise summary | Main methods / deliverable |
|---|---|---|---|
| C01 | **Predicting Rhinoplasty Outcomes Using AI and Facial Image Analysis** — Ali Anaissi | Predict likely post-operative facial appearance from pre-operative photographs for clinical consultation. | GANs/diffusion, facial landmarks, model evaluation, CPU-friendly desktop app |
| C02 | **Privacy-Preserving Medical Vision-Language AI Assistant Using Federated Learning** — Junaid Akram | Train a multimodal medical assistant across simulated institutions without exchanging patient data. | Federated learning, vision-language models, diagnostic explanations |
| C03 | **Explainable Fake Image Detection Using Large Multimodal Models** — Junaid Akram | Classify images as real or AI-generated and provide understandable evidence for the decision. | LMMs, FakeBench, VQA/prompting, text explanations |
| C04 | **LLM-Generated Audio Dialogues for Crisis Detection in Speech** — Junaid Akram | Generate and validate a privacy-safe audio-text benchmark for turn-level crisis detection. | LLM fine-tuning, emotion-conditioned TTS, audio validation, benchmark release |
| C05 | **Platform-Aware Metadata Fingerprinting for Image Provenance** — Junaid Akram | Predict the social platform from which an image was downloaded using metadata fingerprints and calibrated confusion-aware reranking. | Random forest, metadata features, calibration, statistical testing, lightweight reproducible ML |
| C06 | **Vehicle Metadata Identification Using Machine Learning** — Ali Haidar / NSW Police | Extract vehicle make, model, body type, colour, damage, decals, and accessories from imagery. | Computer vision, classification/detection, traffic-camera data |
| C07 | **Vehicle Reidentification Using Deep Learning for Scalable Search** — Ali Haidar / NSW Police and Ali Anaissi | Find the same vehicle across multiple cameras despite viewpoint and lighting changes. | Deep metric/contrastive learning, video analytics, scalable search |
| C08 | **Interactive Surveillance Video Querying Using LLMs and Multi-Camera CCTV** — Ali Haidar / NSW Police | Search CCTV footage using natural-language questions instead of manual review. | Vision-language models, vector retrieval, LLM interface |
| C09 | **Reproducible, Fully Local Comparison of Small Free LLMs for Coding** — Pouya Salpour | Benchmark small open coding models locally for quality, speed, and hardware use. | Ollama/LM Studio, coding benchmarks, reproducible evaluation |
| C10 | **Automated LLM Verification and Assurance** — Pouya Salpour | Build automated checks for LLM correctness, consistency, reasoning quality, and safety. | Test generation, evaluation framework, consistency/assurance metrics |
| C11 | **Grounded AI Assistant for the National Construction Code 2025** — Magtech.ai | Extract a knowledge graph from NCC XML and test graph-grounded retrieval, citation accuracy, and question answering. | XML/XSD, knowledge graphs, graph traversal, RAG, evaluation, deployed assistant |
| C12 | **AI Detection of Floor Slabs from Architectural and Structural Drawings** — Magtech.ai | Detect and segment floor-slab regions in CAD/PDF plans. | Semantic segmentation, YOLO/OpenCV, construction drawings |
| C13 | **Advanced Image Recognition for Household Item Identification** — MyVal | Identify household assets and personalise insurance, warranty, maintenance, and valuation information. | Image recognition, data analysis, valuation workflow/dashboard |
| C14 | **Assessing the Credibility of Organisational Knowledge from Fragmented Data** — Decidr | Assess incomplete and conflicting organisational claims with transparent evidence, calibrated confidence, and explainable reasoning. | LLMs/RAG, information retrieval, knowledge graphs, Bayesian reasoning, calibration |
